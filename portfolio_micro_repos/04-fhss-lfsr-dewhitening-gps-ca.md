## 1. The Engineering Problem

A covert communications link must hide inside an already-busy spectrum. An overt 16-channel frequency-hopping spread-spectrum (FHSS) network provides the perfect cover: its random hop pattern fills the band wall-to-wall, making any narrowband search for the hidden transmitter impossible.

The hidden transmitter uses **GPS C/A Direct-Sequence Spread Spectrum (DSSS)** — the same spreading technology used by GPS satellites. By spreading its signal across the entire 16 MHz recording bandwidth at a power level 20 dB below the FHSS noise floor, it is physically invisible to any spectrum analyser.

Recovering the hidden signal requires solving four independent sub-problems in sequence.

---

## 2. Background: Two Spread-Spectrum Techniques

### 2.1 Frequency-Hopping Spread Spectrum (FHSS)

An FHSS transmitter changes its carrier frequency many times per second, following a pseudo-random sequence known only to the intended receiver. Each burst occupies one of 16 narrowband channels, each 50 kHz wide.

The hop sequence is generated by a **Linear Feedback Shift Register (LFSR)** seeded by the channel number. The output of each frame is whitened (XOR'd with the LFSR output) to randomise the bit statistics. A CRC-16/CCITT at the end of each frame allows frame validation.

```
Hop pattern (16 channels, 50 kHz spacing):
Channel 0:  base_freq + 0 × 50 kHz
Channel 1:  base_freq + 1 × 50 kHz
...
Channel 15: base_freq + 15 × 50 kHz
```

### 2.2 Direct-Sequence Spread Spectrum (DSSS) — GPS C/A

GPS C/A (Coarse/Acquisition) codes are Gold codes of length **1,023 chips** at **1.023 Mchip/s**, giving a period of exactly 1 ms. There are 32 standard PRN codes (PRN 1–32), each with near-zero cross-correlation and an autocorrelation peak of 1,023.

The spreading gain (processing gain) is:

```
G_p = 10 × log₁₀(chip_rate / data_rate) = 10 × log₁₀(1.023 × 10⁶ / 50) ≈ 43 dB
```

This means the DSSS signal can operate **43 dB below the noise floor** and still be recoverable with a matched filter.

## 3. The Four-Stage Pipeline

### Stage 1 — FSK Channelisation and LFSR De-whitening

The overt FHSS network uses **2-FSK** (binary frequency-shift keying). Each channel is demodulated using an FM discriminator:

```
instantaneous_freq(t) = (1/2π) × d/dt [∠IQ(t)]
```

The demodulated bits of each channel are then **de-whitened** by XOR-ing with the LFSR sequence seeded by that channel's index:

```python
# LFSR feedback polynomial: x^16 + x^15 + x^13 + x^4 + 1 (example)
def lfsr_next(state, poly):
    bit = bin(state & poly).count('1') % 2
    return ((state >> 1) | (bit << 15)) & 0xFFFF

whitened_bits XOR lfsr_stream → raw_bits
```

Because the frame start offset within the recording is unknown, every possible bit alignment is tested. The alignment that yields a passing **CRC-16/CCITT** checksum is the correct one. The recovered payload contains the specification for the hidden Ghost Carrier: PRN numbers, timing offsets, and decryption metadata.

### Stage 2 — GPS C/A PRN Acquisition

GPS acquisition uses a 2D search over **code phase** (0–1022 chips) and **Doppler frequency** (± a few kHz due to SDR clock drift). The efficient approach uses FFT-based circular correlation:

```
S(f) = FFT(IQ_block)
P(f) = FFT(PRN_code_replica)

correlation = IFFT(S(f) × conj(P(f)))
peak_to_mean = max(|correlation|²) / mean(|correlation|²)
```

A peak-to-mean ratio > 10 (typically ~40 for a strong signal) confirms the presence of that PRN. In this recording, **PRNs 17, 19, and 32** each produce peak-to-mean ratios of ~40, proving their presence.

### Stage 3 — Spectral Notch Filtering (Not Blanking)

The FHSS bursts occur in the same time window as the DSSS signal. Naively zeroing out (blanking) the FHSS bursts in the time domain would also destroy the DSSS chips underneath them — the DSSS energy is spread across all frequencies simultaneously, including the FHSS hop frequencies.

The correct approach is **spectral notch filtering**: apply tight (< 5 kHz) notch filters in the frequency domain at the exact hop frequencies, leaving the wideband DSSS energy untouched at all other frequencies.

```python
# FFT the block, zero only the bins at FHSS hop frequencies, IFFT back
X = np.fft.fft(iq_block)
for hop_freq in active_hop_freqs:
    bin_idx = round(hop_freq / freq_resolution)
    X[bin_idx - W : bin_idx + W] = 0   # narrow notch, W ~ 5 bins
iq_clean = np.fft.ifft(X)
```

### Stage 4 — DBPSK Decoding and Shamir Reconstruction

**Differential BPSK (DBPSK)** encodes bits in phase *changes* rather than absolute phase:

```
bit = 0 → no phase flip   (Δφ = 0°)
bit = 1 → phase flip      (Δφ = 180°)
```

This is immune to constant phase ambiguity. A Phase-Locked Loop (PLL) tracks the SDR's clock drift (the carrier frequency chirps slowly), allowing the differential phase to be read cleanly.

The three recovered bit streams from PRNs 17, 19, and 32 are **Shamir Secret Shares** combined with XOR:

```
master_key = share_17 XOR share_19 XOR share_32
```

Shamir's Secret Sharing guarantees that any single share leaks zero information about the key — only the combination of all three reveals the secret.

## 4. Mathematical Reference

| Symbol | Meaning |
|--------|---------|
| G_p | Processing gain (dB) = 10 log₁₀(chip_rate / data_rate) |
| N_c | Code length (1023 chips for GPS C/A) |
| T_c | Chip duration = 1 / chip_rate |
| ρ(τ,f) | Ambiguity function — correlation vs code delay τ and Doppler f |
| CRC-16 | Generator polynomial: x¹⁶ + x¹² + x⁵ + 1 (CCITT) |
