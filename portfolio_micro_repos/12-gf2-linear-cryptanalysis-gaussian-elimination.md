# GF(2⁶⁴) Linear Cryptanalysis — Breaking Iterated Hashes via Gaussian Elimination

> **tl;dr:** An adversary authenticates drone flight missions using a 24-bit cryptographic seal generated by an iterated hash over $\text{GF}(2^{64})$. While the 64-bit secret key would require 580 years to brute-force, the cipher suffers from a catastrophic design flaw: every operation is strictly linear over the Galois Field $\text{GF}(2)$. By formulating the hashing process as an affine matrix transformation and collecting 120 linear equations across 5 intercepted missions, we recover the 64-bit key in under 5 milliseconds via Gaussian elimination.

## 1. The Engineering Problem

A hostile unmanned aerial combat vehicle (UCAV) validates mission waypoint packages uploaded via tactical datalink by verifying a 24-bit "mission seal" appended to the file. The seal generation algorithm is an iterated stateful hash function seeded by a secret 64-bit squadron master key $K$:

$$K \in \{0, 1\}^{64} \implies 2^{64} \approx 1.84 \times 10^{19} \text{ possibilities}$$

An Electronic Support Measures (ESM) surveillance post intercepts five legitimate mission command files and their corresponding 24-bit seals (`data/sealed_missions.txt`).

At an evaluation throughput of 1 billion hashes per second ($10^9\,\text{s}^{-1}$), an exhaustive brute-force search across the 64-bit key space requires:

$$\frac{2^{64}}{10^9 \times 3600 \times 24 \times 365.25} \approx 584.5 \text{ years}$$

The cryptanalytic mission is to bypass brute-force complexity entirely, analyze the algebraic properties of the underlying transformation, and recover the 64-bit key within milliseconds.

---

## 2. Why Naive Approaches Fail

1. **Brute-Force & Dictionary Attacks**: The key entropy is full 64-bit pseudo-random data. Wordlists and rainbow tables are completely useless.
2. **Standard Cryptographic Hash Tools**: Tools like Hashcat or John the Ripper optimize for standardized algorithms (MD5, SHA-256, bcrypt). They cannot model custom field polynomial multiplication or arbitrary Galois transformations without a dedicated kernel.
3. **Black-Box Optimization / Hill Climbing**: Because the seal outputs change drastically with single bit flips, gradient descent and genetic algorithms fail across the rugged, non-continuous discrete landscape.

## 3. The Mathematical Foundation

### 3.1 Field Arithmetic over $\text{GF}(2^{64})$

The seal algorithm operates on 64-bit words treated as elements of the Galois Field $\mathbb{F}_{2^{64}} \cong \mathbb{F}_2[x] / \langle P(x) \rangle$, defined modulo the irreducible polynomial:

$$P(x) = x^{64} + x^4 + x^3 + x + 1$$

Multiplication of field elements $A(x) \cdot B(x) \pmod{P(x)}$ is performed via carryless shift-and-XOR operations:

$$a \otimes b = \bigoplus_{i=0}^{63} \left( a \cdot (b \gg i \wedge 1) \cdot x^i \pmod{P(x)} \right)$$

### 3.2 The Flaw: Strict Linearity over $\text{GF}(2)$

A function $f: \mathbb{F}_2^n \to \mathbb{F}_2^n$ is linear over the prime field $\mathbb{F}_2$ if and only if:

$$f(\mathbf{x} \oplus \mathbf{y}) = f(\mathbf{x}) \oplus f(\mathbf{y}) \quad \forall \mathbf{x}, \mathbf{y} \in \mathbb{F}_2^n$$

We examine every primitive operation inside the seal's round function:

1. **Bitwise Circular Rotation (`rotl(x, n)`):**
   $$\operatorname{rotl}(\mathbf{x} \oplus \mathbf{y}, n) = \operatorname{rotl}(\mathbf{x}, n) \oplus \operatorname{rotl}(\mathbf{y}, n)$$
   $\implies$ Pure permutation matrix over $\mathbb{F}_2$. Linear.
2. **Bitwise XOR ($\oplus$)**:
   The native addition operation in $\mathbb{F}_2$. Linear.
3. **Galois Field Multiplication by Constant $C$ (`gf_mul(x, C)`):**
   Because polynomial multiplication distributes over addition:
   $$C \cdot (\mathbf{x} \oplus \mathbf{y}) \equiv (C \cdot \mathbf{x}) \oplus (C \cdot \mathbf{y}) \pmod{P(x)}$$
   $\implies$ Exactly linear over $\mathbb{F}_2$.

**Critical Vulnerability**: The cipher contains **no non-linear elements**. It lacks non-linear substitution boxes (S-Boxes), modular integer additions ($\boxplus 2^{64}$), or AND/OR bitwise masking between state variables. Every operation has an algebraic degree of exactly $1$.

### 3.3 State Transition as an Affine Map

Because the transformation is linear over $\mathbb{F}_2$, the update of the 64-bit state vector $\mathbf{s} \in \mathbb{F}_2^{64}$ upon ingesting message byte $m_k$ can be written as an affine transformation:

$$\mathbf{s}_{k+1} = \mathbf{s}_k \cdot \mathbf{M} \oplus \mathbf{c}(m_k)$$

where:
- $\mathbf{M} \in \mathbb{F}_2^{64 \times 64}$ is the fixed binary state-transition matrix.
- $\mathbf{c}(m_k) \in \mathbb{F}_2^{64}$ is a constant vector injected by message byte $m_k$.

### 3.4 Matrix Exponentiation over $\mathbb{F}_2$

For a mission file containing $N$ bytes $m_1, m_2, \dots, m_N$, the composition of $N$ linear rounds expands to:

$$\mathbf{s}_N = \mathbf{K} \cdot \mathbf{M}^N \oplus \sum_{j=1}^N \mathbf{c}(m_j) \cdot \mathbf{M}^{N-j}$$

$$\mathbf{s}_N = \mathbf{K} \cdot \mathbf{M}^N \oplus \mathbf{v}_{\mathrm{msg}}$$

where $\mathbf{K}$ is the unknown 64-bit key vector, and $\mathbf{v}_{\mathrm{msg}}$ is a known constant vector completely determined by the known mission text.

### 3.5 Constructing the Linear Equation System

The 24-bit seal represents the most significant 24 bits of the final state $\mathbf{s}_N$:

$$\text{Seal}_i = \mathbf{s}_{N, i}[40..63] \quad (24 \text{ observed bits per mission})$$

For each observed bit $j \in \{0, 1, \dots, 23\}$:

$$\bigoplus_{k=0}^{63} \left( K_k \cdot \left(\mathbf{M}^{N_i}\right)_{k, 40+j} \right) = \text{Seal}_{i, j} \oplus \left(\mathbf{v}_{\mathrm{msg}, i}\right)_{40+j}$$

With 5 intercepted missions:

$$\text{Total Equations} = 5 \times 24 = 120 \text{ linear binary equations}$$

$$\text{Total Unknowns} = 64 \text{ key bits}$$

Because $120 \gt 64$, the linear system is **overdetermined**.

### 3.6 Gaussian Elimination over $\text{GF}(2)$

We construct the augmented binary matrix $[\mathbf{A} \mid \mathbf{b}]$ of size $120 \times 65$ over $\mathbb{F}_2$. Applying Gaussian elimination:
1. **Pivot Selection**: Find a row $r \ge i$ with $A_{r, i} = 1$; swap with row $i$.
2. **Forward Elimination**: For all other rows $k \ne i$ where $A_{k, i} = 1$, row-reduce:
   $$\text{Row}_k \leftarrow \text{Row}_k \oplus \text{Row}_i$$
3. **Exact Solution**: Back-substitution yields the unique key vector $\mathbf{K} \in \mathbb{F}_2^{64}$ with zero ambiguity.

## 4. Algorithmic Breakdown

1. **Matrix $\mathbf{M}$ Extraction via Basis Probing**:
   - Evaluate the single-round transition function on all 64 standard basis vectors $\mathbf{e}_i = 1 \ll i$.
   - Assemble the columns into the $64 \times 64$ binary transition matrix $\mathbf{M}$.
2. **Matrix Powering**:
   - Compute $\mathbf{M}^N$ over $\mathbb{F}_2$ using repeated binary squaring in $\mathcal{O}(64^3 \log N)$ steps.
3. **Affine Offset Accumulation**:
   - Propagate message bytes to compute constant offset vector $\mathbf{v}_{\mathrm{msg}}$.
4. **Equation Aggregation**:
   - Slice top 24 bits of $\mathbf{M}^N$ and $\mathbf{v}_{\mathrm{msg}}$ for each of the 5 missions.
   - Stack into a $120 \times 64$ coefficient matrix $\mathbf{A}$ and $120 \times 1$ target vector $\mathbf{b}$.
5. **Gaussian Elimination**:
   - Execute row reduction modulo 2.
   - Extract recovered 64-bit integer key $K$.
